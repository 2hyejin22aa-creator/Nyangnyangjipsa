채널별 역할

채널손님이 하는 일우리가 하는 일
릴스처음 알게 됩니다15~30초 영상으로 노출을 만듭니다
인스타그램분위기와 최근 소식을 봅니다프로필·피드·카드뉴스를 정리하고 꾸준히 올립니다
멀티링크더 알아볼 곳을 고릅니다블로그·플레이스·상담 링크를 한곳에 모읍니다
블로그설명과 후기를 읽고 판단합니다검색에 잡히는 글로 수업·서비스를 설명합니다
네이버 플레이스지도에서 위치·시간·가격·후기를 확인합니다정보·사진·소식을 최신으로 관리합니다
상담 문의연락합니다문의 경로를 기록해 리포트에 담습니다

달라지는 점

진행 방식

  1. 상담상황과 목표 확인 (무료)
  2. 진단현황 점검, 구성 제안 (, 계약 시 차감)
  3. 세팅필요한 채널 정리
  4. 운영월초 일정 공유 후 제작·게시
  5. 리포트월 1회 한 장 정리

월 순환

  1. 월초 기획·미팅
  2. 제작·게시
  3. 중간 점검
  4. 월말 리포트
  5. 다음 달 조정

3개월 동안

  1. 1개월기본기 정비, 시작 전 지표 기록, 첫 콘텐츠
  2. 2개월반응과 문의 경로 확인, 주제 조정
  3. 3개월성과 리뷰, 다음 3개월 방향 재설계

3개월 뒤에 알게 되는 것

  • 문의가 어디서 오는지 보입니다.
  • 어떤 콘텐츠가 통했는지 숫자로 알게 됩니다.
  • 무엇을 더하고 뺄지 근거가 생깁니다.

결과는 업종과 상권에 따라 다르며 보장하지 않습니다.
