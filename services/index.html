가격 보기 카톡 상담

손님이 오는 길

  1. 1릴스가게를 처음 알게 됨
  2. 2인스타그램믿을 만한지 확인
  3. 3멀티링크예약 · 문의 · 지도 · 블로그로 이동
  4. 4블로그 · 플레이스설명 · 후기 · 위치 확인
  5. 5상담 문의전화 · 카톡 · 예약으로 연락

채널별 역할

채널손님이 하는 일내가 하는 일
릴스영상을 보다가 가게를 처음 알게 됨업체 제공 영상 편집, 인스타·클립 동시 업로드
인스타그램프로필을 둘러보고 믿을 만한지 봄카드뉴스·피드로 안내·일정·후기 정리, 프로필·하이라이트 세팅
멀티링크한 곳에서 예약·문의·지도·블로그로 이동링크 모음 페이지 제작·관리
블로그검색해서 설명·후기 글을 읽음검색되는 글 작성, 홈페이지형 블로그 디자인
네이버 플레이스지도에서 위치·사진·리뷰를 확인소식·리뷰 답글·사진·정보·키워드 관리
상담 문의전화·카톡·예약으로 문의문의 경로 기록, 월간 리포트로 어느 길로 왔는지 확인

달라지는 점

진행 방식

  1. 1상담상황과 목표 확인 (무료)
  2. 2진단현황 점검, 구성 제안 (, 계약 시 차감)
  3. 3세팅필요한 채널 정리
  4. 4운영월초 일정 공유 후 제작·게시
  5. 5리포트월 1회 한 장 정리

월 순환

  1. 일정 · 소재 정하기
  2. 제작 · 게시
  3. 지표 확인
  4. 다음 달 조정

소재가 모자라는 달에는 건수를 채우지 않고 일정부터 다시 정합니다.

3개월 동안

  1. 1개월현황 진단 · 세팅 · 첫 콘텐츠
  2. 2개월반응 확인 후 비중 조정
  3. 3개월문의 경로 정리, 계속 · 조정 · 종료를 같이 결정

3개월 뒤에 알게 되는 것

  • 어느 채널에서 문의가 오는지
  • 어떤 콘텐츠에 반응이 있었는지
  • 마케팅이 병목인지, 다른 부분이 병목인지

월간 리포트

자주 묻는 질문

결과를 보장하나요?

문의 수와 노출 순위는 약속하지 않습니다. 매달 숫자와 문의 경로를 보여드리고, 맞지 않으면 3개월 안에 방향을 바꾸거나 멈춥니다.

약정이 있나요?

월 단위로 이용하며 최소 약정은 없습니다. 다음 달 시작 7일 전까지 알려 주시면 해지됩니다. 변화는 3개월 정도 보시길 권합니다. 3개월 플랜은 선결제이며, 중도 해지 시 이용 기간을 정상가로 다시 계산해 남는 금액을 환불합니다.

촬영도 하나요?

업체에서 주신 사진·영상으로 편집합니다. 촬영이 필요하면 월 1회 방문 촬영 옵션()을 선택할 수 있습니다.

세금계산서는요?

개인 프리랜서라 세금계산서는 발행되지 않으며, 3.3% 원천징수로 정산합니다. 금액은 세전입니다.

가격

  • 카드뉴스는 5장 기준 건수입니다.
  • 표기 금액은 세전입니다.
  • 따로 맡기는 금액은 단건·옵션 가격 합계입니다.
  • 카드뉴스는 건당 수정 1회 포함, 추가 수정은 협의합니다.
  • 플레이스 월 관리는 업체에서 전달해 주신 자료 범위 안에서 진행하며, 리뷰 답글은 초안 작성 후 확인을 받고 올립니다.
  • 키워드는 관리하지만 노출 순위는 약속하지 않습니다.

필요한 것만 고르시려면 단건·옵션을 확인하세요
