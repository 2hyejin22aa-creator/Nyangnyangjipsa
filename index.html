    계약 전 걱정

    6개월, 1년 장기계약?

    월 단위로 시작하고, 약정은 없습니다.

    대충 올리고 끝?

    월 1회 리포트로 한 일과 반응을 확인합니다.

    맡겼는데 무엇을 했는지 모르겠다?

    월초에 일정을 공유하고, 월말에 정리해 드립니다.

    광고비까지 맡겨야 할까?

    광고 운영 대행은 하지 않습니다. 광고비는 별도입니다.

    작업 화면

      작업물 전체 보기

      진행이 이렇게 다릅니다

      Point 1

      월 단위로 시작합니다

      1. 상담 (무료)
      2. 진단 (, 계약 시 차감)
      3. 세팅
      4. 운영 시작
      Point 2

      매달 같은 순서로 진행합니다

      1. 월초 기획, 미팅
      2. 제작, 게시
      3. 중간 점검
      4. 월말 리포트
      5. 다음 달 조정
      Point 3

      필요한 만큼만 구성합니다

      1. 현황 진단
      2. 필요한 채널 정리
      3. 패키지로 시작
      4. 단건, 옵션 추가 (패키지 이용 중 할인)

      맡기기 전에 확인하세요

      이런 업체에 맞습니다

      • 올려도 문의가 없는 동네 업체
      • 블로그, 플레이스, 인스타그램을 함께 정리하고 싶은 업체
      • 한 달 단위로 시작해서 확인해 보고 싶은 업체
      • 촬영한 영상을 릴스로 편집해야 하는 업체

      이런 경우는 맞지 않습니다

      • 광고 운영 대행이 필요한 경우 (광고비는 별도입니다)
      • 세금계산서 발행이 필요한 경우 (개인 프리랜서, 3.3% 원천징수)
      • 단기간의 순위나 매출 보장을 원하는 경우

      요금은 월 단위입니다

      최소 약정 없는 월 단위 이용다음 달 시작 7일 전까지 알려 주시면 해지됩니다.
